When an Angular app loads, the browser loads index.html and JavaScript bundles, Angular bootstraps the application, creates the root component, initializes dependency injection and routing, renders the component tree, and then performs change detection to keep the DOM synchronized with application state.

type and interface disffernce
	interface is mainly used to define the structure or contract of objects and classes, while type is more flexible and can define objects, unions, intersections, primitives, tuples, and other type combinations. Interfaces also support declaration merging.
	
what is directive	
	A directive is a special instruction in Angular that allows you to manipulate the DOM, add behaviors, or enhance templates with custom functionality.
	Structural Directives- Shape or structure your DOM elements by adding or removing them
	Attribute Directives- Change the appearance or behavior of an element. ngClass, ngStyle
	Custom Directives- Create your own reusable directives to extend HTML behavior.
What Are Angular Pipes
	Angular Pipes allow you to transform and format data directly in templates without modifying the underlying data. They are great for Formatting dates, numbers, currencies, and text
	{{ today | date:'fullDate' }}
	{{ price | currency:'USD' }}
	{{ 'angular' | uppercase }}
	{{ 'Angular' | lowercase }}
	{{ 1234.56 | number:'1.1-2' }} decimal pipe
	Pure Pipes (Default)-Executes only when the input value changes.
	Impure Pipes - Executes on every change detection cycle, even if the input hasn’t changed.
	@Pipe({
	  name: 'impurePipeExample',
	  pure: false
	})
	export class ImpurePipeExample implements PipeTransform {
	  transform(values: any[]): any[] { }}
Change Detection
	Change Detection in Angular ensures your UI updates efficiently when data changes.
	Angular provides two strategies to control how Change Detection runs:
	Default Strategy- Runs Change Detection on the entire component tree.
	OnPush Strategy- Runs Change Detection only when Input properties change.
	@Component({  
	  selector: 'app-example',  
	  templateUrl: './example.component.html',  
	  changeDetection: ChangeDetectionStrategy.OnPush  
	})  
	export class ExampleComponent {  
	  @Input() data: any;  
	}
	trackBy - use trackBy  for large lists
	Angular will repaint the entire list instead of just modifying the changed item. if we use trackBy, only modified items would be rerendered
Angular Modules	
	Angular Modules are essential for organizing, maintaining, and scaling your applications. An Angular Module is a container that groups related parts of an application, like components, directives, services, and pipes. Every Angular app has at least one module, the root module (AppModule).
	Lazy Loading a Module- Improve performance by loading modules only when needed
