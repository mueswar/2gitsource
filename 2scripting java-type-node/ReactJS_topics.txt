A practical learning order
If you're learning React for real-world development, I'd go roughly:

Components → JSX → Props → State → Events → Forms → Hooks → API Calls → CRUD → Routing → Context → Authentication → State Management → Custom Hooks → Performance → Testing → TypeScript → Deployment.
